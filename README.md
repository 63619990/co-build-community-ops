# 共建社区运营框架（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
面向中文 Web3 内容创作者与创业者。当用户想从 0 搭建"消费即投资、行动贡献即投资"的
  事业共同体，或想把用户/生态资源转为协同资源（四融：融人融智融市场融资源）时激活。
  典型信号："怎么从 0 搭共建社区""怎么让用户变成共建者而不是流量耗材""消费即投资怎么落地"
  "怎么设计黏性工具让社区自增长""怎么用四融把外部资源转为协同动能"。
  不适用：只设计通证分配规则/合约代码（用 S5 贡献计量与分配设计器）；只谈个体怎么接单
  （用 S9 OPC/超级个体）；只做境内合规判断（用 S2 合规边界红线检查）。本 skill 聚焦组织
  范式与运营框架，而非分配机制的代码化、亦非个体侧承接。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `co-build-community-ops`，或用 CLI：
```bash
clawhub skill install co-build-community-ops
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/co-build-community-ops.git
cp -r co-build-community-ops/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `co-build-community-ops/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
